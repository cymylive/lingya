# 图谱优先（graphify-proactive）

让 AI 在开发/修 bug 时**主动查知识图谱**，而不是默认先 grep。

## 能力

| 层 | 说明 |
|---|---|
| 提示词注入 | 往 systemPrompt **第一段**注入触发规则，告诉 AI 什么场景该查图 |
| 6 个工具 | `gq_status` / `gq_explain` / `gq_path` / `gq_godnodes` / `gq_query` / `gq_build` |
| 自动建图 | 启动后 5 秒检查，图缺失或过期则后台重建 |

## 工具一览

| 工具 | 用途 | 典型场景 |
|---|---|---|
| `gq_status` | 看图是否可用、是否过期 | 查结构前先确认 |
| `gq_explain` | 一个符号的全部关系 | 「谁在用这个类」「改了影响什么」 |
| `gq_path` | 两个符号的最短路径 | 「A 和 B 怎么连起来的」 |
| `gq_godnodes` | 度数最高的节点 | 「核心抽象是什么」 |
| `gq_query` | 自然语言查结构 | 英文关键词提问 |
| `gq_build` | 重建图谱 | 图缺失/过期时 |

## 与 grep 的分工

**查图**：结构关系、影响面、调用链、架构
**grep**：找具体字符串、找配置项、看代码原文

## 自定义提示词

侧栏「🕸️ 图谱」面板里有文本框，可改写触发规则。留空则用内置默认。

默认规则要点：
- 涉及「谁在用」「影响面」「怎么连起来」→ 优先查图
- 找具体字符串 → 仍用 grep
- 图过期时先 `gq_build`

## 已知限制（如实说明）

1. **提示词只能提高触发率，不能强制**。AI 可能仍然直接 grep。这是提示词机制的固有局限，不是 bug。
2. **`gq_query` 中文不可用**。打包时未包含 jieba 分词扩展，需用英文关键词。`gq_explain` 直接点名不受影响。
3. **图会过期**。本插件检测过期（比对源码 mtime），但不会实时同步。改动密集时建议手动 `gq_build`。

## 依赖

- `resources/graphify/graphify.exe`（随 LingYa 分发）
- 图谱落在 `<userData>/graphify/graph.json`

## 配置项

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 是否注入提示词 |
| `autoBuild` | true | 启动时是否自动建图 |
| `staleMinutes` | 30 | 超过多少分钟视为过期（0 = 不按时间判断） |
| `customPrompt` | "" | 自定义触发规则，留空用默认 |
